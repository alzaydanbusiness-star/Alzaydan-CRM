# Al Zaydan International FZE - Enterprise CRM

Official enterprise customer relationship management and commercial sales operations platform for **Al Zaydan International FZE**.

---

## 🌟 Key Features

- **Executive Commercial Dashboard**: Real-time sales pipeline, KPI metrics, deal conversion tracking, and monthly revenue analytics.
- **Lead & Customer Lifecycle**: End-to-end customer management, multi-contact directory, qualification, and stage monitoring.
- **Streamlined Sales Operations**:
  - **Opportunities**: Interactive deal stage tracking (Enquiry, Qualification, Offer Sent, Negotiation, Won, Lost) with dynamic win probability.
  - **Commercial Quotations**: Professional quotation generator with multi-currency, VAT (5%), and print formats.
  - **Sales Orders**: Direct conversion from approved quotations with automated approval flows.
  - **Tax Invoices**: UAE VAT-compliant billing, auto-calculation, and PDF-ready vouchers.
  - **Receipts**: Official payment acknowledgements, bank settlement tracking, and payment ledger.
- **Role-Based Access Control**: Tailored workflows for Super Admin, Sales Manager, Team Leads, and Field Sales Representatives.

---

## 🚀 Tech Stack

- **Frontend**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Notifications**: [Sonner](https://sonner.emilkowal.ski/)
- **Linter**: [Oxlint](https://oxc.rs/)

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/alzaydanbusiness-star/Alzaydan-CRM.git
cd Alzaydan-CRM
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
```
